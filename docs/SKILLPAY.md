# SkillPay 商品材料

本文为 **0.5.0 自进化版本的待发布材料**，不代表该版本已上架。
之前发布的商品不会自动获得这些新能力；团队参赛应由团队报名账号重新上架并记录新商品链接。

## 商品名称

自进化字幕｜把校对变成下一期的经验

一句话：从改稿、词库和联网资料学习，先看改前对照，再应用到下一期字幕。

## 商品描述（500 字内）

同一个术语，每期都要重新改？把这次校对留下来，下一期让 Agent 复用。

自进化字幕面向连续制作课程、访谈、知识视频和产品演示的创作者。从审阅后的改稿、本地词库和联网资料积累经验；每条规则通过正例、反例和旧案例回归后才会生效。

先看再改：逐句预览原译文、建议改稿和证据引文，不动原文件。确认后，程序按频道、语言和领域执行术语统一、精确句子翻译与原文纠错。规则能停用，自动改稿能撤回；证据过期或版本失效时拦截交付。

例如课程里的 agent 使用「智能体」，房产语境保留「经纪人」。本地导出 SRT、VTT、ASS、可编辑项目和检查报告，支持分批翻译。

购买获得本地 Skill 文件和可复现演示。需 Python 3.9+；识别视频另需安装媒体依赖和下载模型，独立翻译 API 费用自理。自进化是知识与规则积累，不是模型训练，也不保证零错。源码同时按 MIT 开源。

## 三个差异点与宣传依据

| 差异点 | 面向用户的表达 | 对应证明 |
|---|---|---|
| 字幕经验能复用 | 把一次校对，变成下一期的字幕经验 | 改稿和词库形成规则，下一段字幕实际变化 |
| 每次改动能解释 | 先看哪句改、为什么改，再决定应用 | `evolve preview` 的逐句 HTML 对照与来源引文 |
| 记住经验也有边界 | 规则有范围，出错能停用、能撤回 | 房产反例、回归测试、过期/失效拦截与撤回 |

封面：[PNG 上传版](../assets/cover.png) / [SVG 源文件](../assets/cover.svg)，1200×620；已检查文字与布局。
搜索词：双语字幕、字幕校对、课程字幕、术语统一、本地知识库、字幕记忆、Agent Skill。
不使用「越用越准确」「自动理解所有领域」「节省 80% 时间」「永久免费算力」「独家源码」等未经验证的承诺。
避免把 Whisper、普通翻译或字幕导出单独包装成核心创新。

## 演示

执行 `python -m subtitler evolve demo --online --output new-demo`，打开 `new-demo/index.html`。
展示第一次改稿如何用于下一段、房产语境未被错误套用、联网术语实际进入字幕、违规交付被拦截和修改撤回。
演示使用原创文本与公开术语，是程序实际执行结果，不是 ASR 准确率或真实用户效率指标。

先体验核心功能，无需下载模型或调用独立付费 API：

```bash
python -m pip install .
python -m subtitler doctor --core
python -m subtitler evolve demo --output my-first-demo
```

从项目/Skill 文件夹运行，打开 `my-first-demo/index.html`，查看改前预览、实际改稿、三个拦截和撤回结果。
开始处理视频时再安装 `python -m pip install ".[media]"`，运行完整 `doctor`，按 README 操作。

付费价值是已打包并验证的 Skill 工作流、可预览/可撤销的程序、原创演示和故障说明。
源码同时开源，技术用户可以自行安装；购买不附带独占授权、人工代做、长期服务时效或未承诺的后续版本权益。

## 支付与上架边界

本项目通过 SkillPay 销售技能文件，不另写一个未经文档支持的收费接口，
不接管用户付款授权。推荐先验证一次性购买、本地执行的交付方式。
周期付费依赖平台云端执行，Python、FFmpeg、模型或浏览器能力是否可用尚待核实。

官方入口：
- [商品管理](https://skillpay.alipay.com/creator/products?aipay_choose_perspective=1)
- [新建商品](https://skillpay.alipay.com/creator/product-new)
- [SkillPay 说明](https://skillpay.alipay.com/)
- [PAYATHON 2026](https://aipay.alipay.com/community/events/payathon-2026)

2026-10-20 查阅的公开新建页支持 .zip、.md、文件夹，提示单文件不超过 20 MB，
买断/周期收费模式选择后不可修改。新建页列出 SkillPay、AI 按量付费、即刻收
三个协议，首页则只提及前两个：以登录后的实际签约页面为准，不能把页面模板
当成当前账号已签约。商品审核与比赛投稿是两个动作。

## 提交前与提交后

1. 核对卖家收款账号与团队报名账号一致，由账号持有人完成必要签约；不要复用其他账号的商品链接。
2. 从 dist 上传白名单 ZIP，使用本页的商品描述；价格和买断模式确认后再提交。
3. 保存审核结果、正式商品 URL、实际售价与版本；没有结果时状态保持“待审核”。
4. 用真实购买意愿用户验证“展示商品 → 支付确认 → 下载/安装 → 运行 → 得到交付”。
   不自买刷量，不伪造支付或点赞数据。
5. 用真实故障验证售后路径；截图需遮挡账号、支付信息和用户素材。
6. 在比赛页单独选择 Skill Pay 投稿，填写真实商品链接、版本、演示和测试范围。
   不把自动测试数当付费用户数，不把合成演示当业务成交。

仓库开源许可继续有效。客服入口暂用本仓库 Issues（只放脱敏问题）；
交易争议和退款按平台流程由卖家处理，不在公开 Issue 放订单、手机号或密钥。

## 支付到交付的验收

官网说明一次性付费交付 Skill 明文；消费者在 Agent 展示商品和价格后确认购买。
退款先联系开发者协商，再由开发者在商品页面发起。依据：[SkillPay 官网](https://skillpay.alipay.com/)（2026-10-20 查阅）。
本地工具不索要支付密码，不自造支付接口，也不声称提供本地代码 DRM。

| 环节 | 本版完成标准 | 当前证据 |
|---|---|---|
| 商品与身份 | 团队报名账号、新商品 URL、实际售价与版本对应 | 待团队账号发布/核对 |
| 购买与权益 | 独立真实用户确认支付，平台显示成功并获得对应权益 | 待实测；不能用本地 demo 替代 |
| 下载与安装 | 安装新包，`doctor --core` 和原创 demo 成功 | 本地隔离环境验证；平台下载路径待验证 |
| 实际使用 | 完成用户授权素材，第二期复用审阅过的经验 | 原创样例通过；真实双期用户案例待补 |
| 取消与恢复 | 未付款不授予权益；已付款未交付按同一订单排查，避免重复购买 | 待平台实测 |
| 售后 | 按官方流程处理故障/退款，保存脱敏结果 | 待真实适用场景验证，不为刷数据制造退款 |

上架前核对 `PACKAGE.json` 的源码 revision、`dirty:false` 与 ZIP SHA-256。当前仓库没有最新版本的真实付费用户或互动统计，
不能据此申报销量。执行建议见 [四项评分复核](LAUNCH_REVIEW.md)。

## 30 秒演示文案

“做系列视频，最烦的是同一个词每期都要改。这个 Skill 会把审阅过的改稿、词库和资料变成字幕经验。
看这里，课程里的‘代理’改成了‘智能体’，房产里的‘经纪人’保持原样。每一句都能先预览、看依据；
通过测试才会应用，改错能撤回。最后拿到可编辑项目和三种字幕文件。
适合持续做课程、访谈和知识视频的人，先用原创演示看效果，再决定是否适合自己的工作流。”
