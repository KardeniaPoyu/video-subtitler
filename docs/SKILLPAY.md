## 商品名称

Video Subtitler｜可修改的双语字幕交付

## 商品描述（500 字内）

把你有权处理的视频整理为可修改的字幕项目，通过 Agent 完成翻译与修订，导出 SRT、VTT、ASS 和检查报告。支持词库、字幕预览与压制；漏译、重叠等错误会阻止正式交付。需本地 Python、FFmpeg 和 Whisper 模型；识别模型首次下载，独立翻译 API 费用另计。检查不保证识别或翻译准确，关键内容仍需人工复核。

## 演示

原创合成字幕：demo → 打开 review.html → 展示三种字幕与可编辑项目；再展示漏译会阻止正式交付。真实视频另录，不使用未授权影视片段。

## 支付与上架边界

本项目通过 SkillPay 销售技能文件，不另写一个未经文档支持的收费接口，
不接管用户付款授权。推荐先验证一次性购买、本地执行的交付方式。
周期付费依赖平台云端执行，Python、FFmpeg、模型或浏览器能力是否可用尚待核实。
